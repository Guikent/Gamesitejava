# 🎮 Game Store

## 📖 Descrição do Projeto

A Game Store é uma aplicação web desenvolvida utilizando Java, Spring Boot, HTML e CSS. O sistema foi criado com o objetivo de aplicar os conhecimentos adquiridos em desenvolvimento web, programação orientada a objetos, integração entre front-end e back-end e persistência de dados.

A interface foi desenvolvida inicialmente utilizando HTML e CSS e posteriormente integrada ao back-end construído com Java e Spring Boot.

---

# 🖥️ Front-End

O front-end é responsável pela interação com o usuário e pela apresentação visual do sistema.

### 📄 Páginas Desenvolvidas

* 🏠 home.html
* 🌐 index.html
* 👤 cadastro.html
* 🔑 login.html
* 🎮 game.html
* 📞 suporte.html

### 🎨 Tecnologias Utilizadas

* HTML5
* CSS3

### ✨ Funcionalidades da Interface

* Navegação entre páginas

* Exibição de jogos

# 📚 Conceitos de Programação Orientada a Objetos Aplicados

Durante o desenvolvimento do projeto foram utilizados conceitos fundamentais de Programação Orientada a Objetos (POO).

## 🔒 Encapsulamento

O encapsulamento foi aplicado nas classes de entidade, como:

* Usuario.java
* Jogo.java

Os atributos são protegidos dentro das classes e acessados por meio de métodos específicos, garantindo maior segurança e organização do código.

## 🧬 Herança

O conceito de herança foi estudado e considerado durante o desenvolvimento da aplicação, permitindo compreender a reutilização de código e a criação de hierarquias entre classes.

## 🔄 Polimorfismo

O polimorfismo foi abordado como princípio da Programação Orientada a Objetos, possibilitando que métodos possam apresentar diferentes comportamentos conforme o contexto de utilização.

## 🏗️ Abstração

A abstração foi utilizada para representar elementos do mundo real através das entidades do sistema, como:

* Usuário
* Jogo

Essas classes modelam informações essenciais para o funcionamento da aplicação.
